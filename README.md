📋 თვითშემოწმების პასუხები (შეკითხვებზე პასუხები):
რა ემართება ელემენტის გარე ზომას content-box-ის დროს, როდესაც padding-ს ვზრდით?

პასუხი: ელემენტის გარე (საბოლოო) ზომა ეკრანზე იზრება. რადგან content-box-ის დროს width განსაზღვრავს მხოლოდ კონტენტის ზომას, ნებისმიერი დამატებული padding ემატება ამ სიგანეს.

რა ემართება კონტენტის (შიგთავსის) ადგილს border-box-ის დროს, როდესაც padding-ს ვზრდით?

პასუხი: ელემენტის გარე ზომა რჩება უცვლელი, ხოლო კონტენტისთვის განკუთვნილი შიდა სივრცე მცირდება "იწურება". padding იკავებს ადგილს შიგნიდან.

რატომ ითვლება border-box თანამედროვე ვებდეველოპმენტის ოქროს სტანდარტად?

პასუხი: border-box ხდის განლაგებას (Layout) სრულად პროგნოზირებადს. დეველოპერს აღარ უწევს მათემატიკური გამოთვლები იმის დასათვლელად, თუ რა ზომის გამოვა ელემენტი padding-ისა და border-ის დამატების შემდეგ, რაც თავიდან გვაცილებს ელემენტების ჩამოშლას/გადავარდნას (Broken Layout).
